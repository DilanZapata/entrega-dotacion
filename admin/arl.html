ARL de Contratistas

El sistema avisa cuando toca revisar la ARL de cada contratista: cada 30 días, y cuando la vigencia está por vencer o ya venció.

La ARL no se puede validar automáticamente: la consulta oficial (RUAF) pide un código de verificación que debe resolver una persona. Usa Consultar para abrir la consulta (la cédula queda copiada para pegarla), confirma que la afiliación esté activa y luego marca Revisada hoy.

Agregar contratista

Elige un trabajador ya registrado para marcarlo como contratista. Si aún no existe, créalo primero en "Empleados".
